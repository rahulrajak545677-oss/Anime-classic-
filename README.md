# Classic Anime
Open this folder in Android Studio (Koala+), let it sync (it creates the Gradle wrapper), then Run.
Catalog data comes from the free AniList API; "Where to watch" opens official streaming links only. No video is hosted.
Next: Room for a persistent watchlist, search, decade filters, palette-tinted detail pages.

## Streaming
The "Free to stream" row reads catalog.json from this repo (raw GitHub URL in Catalog.kt). Only add videos you own or that are public domain / openly licensed. Supports MP4 and HLS (.m3u8) via Media3.
